# 课程作业原始评分要求

此文件保存项目最初的课程评分要求，避免在项目主页中混入面向评分的内容。

| 要求 | 分值 | 说明 |
| --- | ---: | --- |
| 服务器正常监听并接受连接 | 15 | 正确使用 `socket`、`bind`、`listen` 和 `accept` |
| 客户端成功连接服务器 | 10 | `connect` 成功 |
| 支持两个客户端连接并交互 | 20 | 服务器能够管理两个连接 |
| 出拳同步与胜负判断正确 | 20 | 不提前泄露对方选择 |
| 多轮游戏和比分统计 | 10 | 可以重复进行多局 |
| 使用多线程或多进程处理并发 | 15 | 包含并发控制 |
| 代码规范、注释和 README | 10 | 保持可读性 |
| 附加要求 | — | 超时判负与断线重连 |

## 超时与重连要求

- 超时判负时间默认为 10 秒。
- 服务器断开时，两个玩家最多尝试重连 5 次，每次间隔 3 秒；服务器恢复后游戏重新开始，比分归零。
- 玩家断开超过 10 秒后再连接时，根据超时规则判定该玩家本轮失败，随后保留比分继续游戏。
