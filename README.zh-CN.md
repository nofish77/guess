# TCP 剪刀石头布网络对战游戏

[English](README.md)

这是一个使用 C、TCP Socket 和多线程实现的双人命令行剪刀石头布游戏。服务器负责同步双方出拳、统计多轮比分、执行 10 秒超时判负，并处理连接恢复。

## 主要功能

- 基于 TCP 的双人网络对战
- 使用线程并发处理玩家连接
- 使用互斥锁保护共享游戏状态
- 支持多轮对战和比分统计
- 玩家 10 秒内未出拳时自动判负
- 包含断线重连和状态恢复逻辑
- 对 Windows 与 Unix Socket API 进行条件编译适配

## 架构

```text
┌──────────┐        TCP        ┌──────────────┐        TCP        ┌──────────┐
│ 玩家 1   │ ◀───────────────▶ │ 游戏服务器   │ ◀───────────────▶ │ 玩家 2   │
│ 客户端   │                   │ 端口 8888    │                   │ 客户端   │
└──────────┘                   └──────────────┘                   └──────────┘
                                      │
                             出拳、超时、比分和
                               连接状态管理
```

服务器为每位玩家创建处理线程，并使用独立线程检查超时。玩家选择、比分和连接状态由互斥锁保护。

## 当前仓库状态

仓库目前包含服务器源码和预编译的 Windows 客户端。原始提交历史中没有 `client.c`，因此暂时保留 `client.exe`，避免项目在 Windows 上完全无法运行。后续最优先的工作是找回并提交客户端源码。

## 编译

### Unix 类系统

使用 Make：

```bash
make
```

或者直接运行：

```bash
cc -Wall -Wextra -pthread server.c -o server
```

### Windows

使用 MinGW GCC：

```powershell
gcc server.c -o server.exe -lws2_32
```

更完整的说明见 [BUILDING.md](BUILDING.md)。

## 运行

1. 启动服务器：

   ```bash
   ./server
   ```

   Windows 下运行 `server.exe`。

2. 分别启动两个客户端。目前仓库只提供 Windows 版 `client.exe`。

3. 按提示输入：

   - `1` — 剪刀
   - `2` — 石头
   - `3` — 布

4. 输入 `y` 继续下一轮，输入 `n` 退出。

服务器默认监听 TCP 端口 `8888`，客户端默认连接 `127.0.0.1:8888`。

## 配置

主要配置以源码中的宏定义提供：

- `PORT` — 服务器端口，默认 `8888`
- `BUFFER_SIZE` — 网络缓冲区大小
- `TIMEOUT_SECONDS` — 出拳超时，默认 10 秒
- `SERVER_IP` — 找回客户端源码后可配置的服务器地址

## 已知限制

- 客户端源码目前缺失。
- 仓库中的客户端二进制文件仅支持 Windows。
- 通信协议为明文，不包含身份认证或加密。
- 当前服务器一次只支持一场双人对局。
